Put your CSV files here, directly or inside any depth of subfolders.
This directory starts without sample CSVs to avoid mixing examples with real data.
Required filename: YYYY-MM-DD_Station_<station_id>_W<worker_id>_<A|M|N>.csv
Example: 2026-09-30_Station_03_W0012_M.csv
CSV first row must contain unique, non-empty column names.
